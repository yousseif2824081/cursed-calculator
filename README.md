# Cursed Calculator

this is a website that looks like a normal calculator but gives you the wrong answer always. type the math problem and press = and the wrong answer will appear. there is also a counter for the wrong answers the calculator got and some funny comments.

**demo:** [Link](https://yousseif2824081.github.io/cursed-calculator/)

## how this was made

this was made by html and css and javascript. the calculator always gives the wrong answers, it first finds the correct answer and then choose a random curse from javascript curse array and ruin the number then prints it on the screen for the user. it also have some funny comments ;)

## how to run

download the files and open `index.html` in your browser. Required files are index.html and style.css and script.js, the readme.md and license are not required to be downloaded.
